วิธีอัปเดตยอดโดเนทให้สมจ๋อยโต
================================
1. เปิดไฟล์ state.json
2. แก้ตัวเลข
     "total"      = ยอดโดเนทรวมทั้งหมด (บาท)
     "supporters" = จำนวนคนที่โดเนท
     "updated"    = วันที่อัปเดต (รูปแบบ 2026-09-30T10:00:00Z)
3. เซฟ แล้วอัปโหลดไฟล์ state.json ขึ้นเว็บทับของเดิม
   (ถ้าใช้ GitHub Pages: กดแก้ไฟล์บนเว็บ GitHub ได้เลย ไม่ต้องอัปโหลดใหม่ทั้งเว็บ)

ไม่ต้องแตะ index.html เลย ยกเว้นอยากเปลี่ยนข้อความ/ลิงก์
ลิงก์ต่าง ๆ อยู่ในส่วน <section aria-labelledby="h-read"> ของ index.html
